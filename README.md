# Privacy Policy & Terms of Service

This repository contains the legal documents required for the Discord bot.

## Files

- `PRIVACY_POLICY.md` — Explains what data the bot collects, how it is used, and how users can request deletion.
- `TERMS_OF_SERVICE.md` — Rules for using the bot and limitations of liability.

## How to use

1. **Customize the documents**
   - Replace `[Bot Name]` with your bot’s actual name.
   - Replace `[Your Name / Contact Email]` with your real contact information.
   - Update the data collection sections so they match **exactly** what your bot stores.

2. **Host the files**
   - Easiest free options:
     - GitHub Pages (recommended)
     - GitHub Gist (public)
     - Any free static host (Carrd, Netlify, etc.)

3. **Add the links in the Discord Developer Portal**
   - Go to [Discord Developer Portal](https://discord.com/developers/applications)
   - Select your application → **App Information**
   - Paste the public URLs into the **Privacy Policy** and **Terms of Service** fields.

4. **Keep them updated**
   - If you change what data the bot collects or how long it is stored, update these documents and the links.

## Important

These are starting templates only.  
They are **not legal advice**. Make sure the Privacy Policy accurately describes what your bot actually does.
